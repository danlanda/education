# הפעלת "שומרי הזמן" באוויר

**האתר באוויר:** https://education-eight-topaz.vercel.app

- Supabase: הפרויקט `education game` (נוצר דרך Vercel). הטבלאות וההרשאות כבר נוצרו
- Vercel: הפרויקט `education`. כל המשתנים מוגדרים, כולל מפתחות ההתראות

רוב העבודה אוטומטית. מה שצריך ממך: לפתוח שני חשבונות חינמיים וליצור שני "מפתחות גישה". את המפתחות מזינים בטופס מאובטח, לא בצ'אט.

## מה אתה עושה (כ־15 דקות)

### 1. להפוך את המאגר ב-GitHub לפרטי (מומלץ)
github.com/danlanda/education ← **Settings** ← למטה ב-**Danger Zone** ← **Change visibility** ← **Private**.
Vercel עובד גם עם מאגר פרטי, בחינם.

### 2. Supabase (מסד הנתונים)
1. נכנסים ל-supabase.com ← **Start your project** ← נרשמים עם GitHub.
2. **New project**:
   - Name: `shomrei-hazman`
   - Database Password: לוחצים **Generate**, ושומרים במקום בטוח
   - Region: **Central EU (Frankfurt)**, הכי קרוב לישראל
3. יוצרים מפתח גישה: לוחצים על התמונה שלך למעלה ← **Account preferences** ← **Access Tokens** ← **Generate new token** ← שם: `claude`.
   מעתיקים את המפתח. כשאבקש, תדביק אותו בטופס המאובטח שיופיע.

### 3. Vercel (האתר)
1. נכנסים ל-vercel.com ← **Sign Up** ← **Continue with GitHub**.
2. כשהוא שואל, מאשרים ל-Vercel גישה למאגר `education`.
3. יוצרים מפתח גישה: **Settings** ← **Tokens** ← **Create**. שם: `claude`, Scope: החשבון שלך, Expiration: 90 days.
   מעתיקים. גם אותו תדביק בטופס המאובטח.

## מה אני עושה אחרי זה (אוטומטית)
1. יוצר את כל הטבלאות וההרשאות ב-Supabase (`supabase/migrations/0001_init.sql`)
2. מחבר את Vercel למאגר ומגדיר את המשתנים: מפתחות Supabase ומפתחות התראות (נוצרים אצלי ונשמרים רק ב-Vercel)
3. מעלה את האתר ובודק שהכול עובד: הרשמה, משחק, אזור הורים, התראות

## אחרי שהאתר באוויר
1. **בטלפון שלך:** נכנסים לכתובת ← נרשמים ← ממלאים את השאלון ← בוחרים "המכשיר של ההורה".
   - **אייפון:** כפתור השיתוף ⬆️ ← **הוסף למסך הבית** ← פותחים מהאייקון ← **הפעל התראות**
   - **אנדרואיד:** **הפעל התראות** ישר מהדפדפן
   - לוחצים "שלח התראת בדיקה" ובודקים שהגיעה
2. **בטאבלט של הילד:** נכנסים עם אותו משתמש ← בוחרים "המכשיר של הילד". מעכשיו הוא נפתח ישר למשחק. היציאה לאזור ההורים דורשת קוד (ברירת מחדל 1234, כדאי לשנות בהגדרות)
3. מוסיפים את האתר למסך הבית גם בטאבלט, כדי שייראה כמו אפליקציה

## משתנים (לידיעה בלבד)
ראו `.env.example`. המפתח הסודי של Supabase ומפתח ההתראות הפרטי נשמרים רק ב-Vercel, אף פעם לא בקוד.

## הרצה מקומית (למפתחים)
```bash
npm install
npm run dev
```
בלי קובץ `.env.local` האפליקציה רצה ב**מצב הדגמה**: הכול נשמר בדפדפן, ו"אבא" עונה אוטומטית.
